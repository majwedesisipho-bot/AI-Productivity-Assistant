# AI Workplace Productivity Assistant

One integrated, AI-powered workspace that helps professionals write, summarise, plan and research —
without switching between five different tools.

## The problem

Knowledge workers lose hours every week to repetitive writing, unstructured meeting notes, messy
to-do lists and shallow research. Existing AI tools solve one slice each, so context is lost between
them. This application brings those tasks into a single platform where the output of one tool feeds
directly into the next.

## Features

| Feature | What it does |
| --- | --- |
| **Dashboard** | Personalised greeting, usage statistics, quick actions, recent activity, recent outputs and a productivity insight. |
| **Smart Email Generator** | Writes professional emails from recipient, purpose, key points, tone, length and desired action. |
| **Meeting Notes Summarizer** | Converts raw notes into an executive summary, key decisions and owned action items. |
| **AI Task Planner** | Prioritises tasks and produces a time-blocked daily or weekly schedule with recommendations. |
| **AI Research Assistant** | Produces a structured brief: summary, insights, findings, recommendations, open questions and limitations. |
| **AI Chatbot (Aura)** | Conversational workplace assistant with full message history. |
| **Settings** | Display name, light/dark theme, notification preference and clearing stored activity. |

### Integration between tools

Open action items generated by the **Meeting Notes Summarizer** can be pushed straight into the
**AI Task Planner** as real tasks, with owner, priority and deadline preserved.

## AI functionality and prompt engineering

Every tool builds its prompt through a shared structured framework in `src/lib/prompts.ts`:

```
ROLE → CONTEXT → OBJECTIVE → CONSTRAINTS → OUTPUT FORMAT
```

- **Role** sets the professional persona for the task.
- **Context** is populated dynamically from the user's real inputs.
- **Objective** states the single outcome required.
- **Constraints** forbid invented facts, fake citations, fabricated dates, owners or commitments.
- **Output Format** specifies plain text or strict JSON so responses render reliably.

Model calls run through the Lovable AI Gateway using Gemini Flash, in a non-streaming server route.

## Responsible AI

- A persistent disclosure appears in the app footer and on every tool page.
- All generated content is editable before it is copied or used.
- Prompts explicitly prohibit fabricated sources, statistics and claims of live browsing.
- The Research Assistant surfaces a visible source-verification warning and a limitations section.
- Users are advised not to enter confidential or personal information.

## Security

The AI provider key is read from the `LOVABLE_API_KEY` environment variable inside the server route
at `src/routes/api/ai.ts`. It is never bundled into or exposed to the browser; the frontend only
calls the app's own `/api/ai` endpoint.

## Technologies

- React 19 + TypeScript
- TanStack Start (routing, server functions) + Vite
- Tailwind CSS v4 with semantic design tokens
- shadcn/ui components and Lucide icons
- Lovable Cloud AI Gateway (Gemini Flash)
- Browser localStorage for tasks, activity and preferences

## Setup

```sh
npm install
npm run dev
```

Set the environment variable before running:

```
LOVABLE_API_KEY=your_key_here
```

In Lovable this key is provisioned automatically; no manual configuration is required.
